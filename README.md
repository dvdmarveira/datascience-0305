# 📊 Tratamento de Dados para Análise

Este repositório contém arquivos e anotações relacionados ao meu processo de aprendizado no **tratamento de dados para análise**. O objetivo é desenvolver habilidades essenciais para a limpeza, transformação e preparação de dados com foco em análise exploratória e construção de insights.

## 🧠 Objetivos do Repositório

- Praticar técnicas de limpeza e padronização de dados
- Trabalhar com diferentes fontes e formatos (Excel, JSON, CSV, etc.)
- Identificar e tratar valores nulos e inconsistências
- Aplicar transformações e agregações úteis para análise
- Documentar aprendizados e boas práticas

## 🛠️ Ferramentas e Tecnologias Utilizadas

- Python (pandas, numpy, openpyxl, etc.)
- Jupyter Notebook
- Power BI
- Google Colab (quando necessário)
- Git
